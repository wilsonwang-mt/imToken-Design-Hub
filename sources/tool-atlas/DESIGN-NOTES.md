# 工具图鉴：方向与范围

受众是正在准备黑客松与培训的Wilson。主要任务是找到自己推荐过的工具、理解能做什么、选择首个练习，随后访问官网或学习教程。

采用直接制作路线。用户已经指定浅色、每项大卡片、Logo、完整介绍和可交互分类，无需再做风格选择。

| 决定 | 依据 | 应用 |
| --- | --- | --- |
| 白色画布与真实品牌图标 | 用户light mode和Logo要求 | 图片是工具身份，保留来源，不虚构产品图 |
| 双列大卡片 | 用户每个工具一张大卡片 | 默认直接看到用途、输出；操作细节在详情中 |
| 克制的表面、细分隔、清晰文字 | Refero Tailark Pro风格afc83cd4-b2da-462d-b116-a8af20f9f3a8 | 借用白色展柜与内容先行，不采用装饰插画和紫色CTA |
| 分类侧栏和搜索 | Refero Fonts In Use风格470e5fb7-8e29-4b30-acc5-fb2907d86b51＋用户交互要求 | 让目录承担首屏任务；放大原参考的小字以适应中文阅读 |
| 蓝色只用于选中和操作 | imToken现有学习库 | 不给不同厂商品牌强制换色 |
| 工具、模型、Skill分别标记 | 用户名单含不同类型 | 产品家族分入口介绍；不把模型当独立应用 |

交互范围：关键词搜索、类别和任务筛选、最多三项比较、详情、复制练习Prompt。无账户、付费、发布或外部数据写入。单文件HTML内嵌内容与Logo，可本地打开；官网和引用链接需要网络。

完整信息包括名称、网址、定位、输入、适用任务、产物、上手步骤、练习、搭配、能力边界、资料来源与实操记录。研究基于官方来源，实操状态基于已有任务台账。
