# 设计工具图鉴

打开[index.html](index.html)。浅色界面，中文为主，收录Wilson推荐的18个工具／产品入口及3项Skill／审阅资源。

每项有大卡片、标识、网址、分类、用途、产物与使用指南。详情包含输入、三步流程、首练Prompt、限制、搭配和资料来源。支持搜索、分类与任务组合筛选、排序、最多三项比较；按“/”聚焦搜索，Esc关闭详情。

内容、样式、交互和21项标识内嵌于HTML。外部官网需网络；本地教程链接指向现有学习资料库。imToken个人插件提供Skill说明副本，没有虚构公开官网。Seedance采用Seed母品牌，Claude入口共用Claude标识，ChatGPT／Codex采用OpenAI母品牌，两个开源资源采用GitHub资源图标；详情与logo-manifest.json记录来源。

三位Agent分别整理设计工具、AI入口和标识，主Agent完成页面与Skill资料。独立审查补充了复制反馈、长词换行和比较托盘焦点处理，搜索逻辑检查补充了用户使用过的Higgfied拼写别名。

已检查：21项字段和标识、本地链接、唯一ID、脚本语法、9组搜索和筛选逻辑；另通过标识拼图检查21项图形。结果见[CHECKS.json](CHECKS.json)。
