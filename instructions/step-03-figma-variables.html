Workflow / Step 03
STEP 03 — 核心步骤

导入 i18n → Figma Variable Collection

将开发的 i18n 文件转换并导入 Figma，创建多语言 Variable Collection，绑定文本图层

Designer — 负责执行
Phase A

将 i18n JSON 转换为 Figma 可导入格式

1

从 GitHub 获取开发的 i18n JSON 文件

下载开发在 Step 02 提交的 en.json 文件。

2

运行转换脚本，生成 Variable Importer 格式

使用 i18n2figma 脚本将 dev i18n JSON 转换为 Variable Importer/Exporter 插件可识别的格式，同时生成三语 Mode 的初始值（中文部分先填入初稿翻译）。

● copy-collection.json — Variable Importer 格式 
{
  "collections": [{
    "name": "Copy",
    "modes": ["EN", "ZH-Hans", "ZH-Hant"],
    "variables": {
      "goldenSeason": {
        "badge": {
          "type": "string",
          "values": {
            "EN": "New Listing",
            "ZH-Hans": "最新上线",
            "ZH-Hant": "最新上線"
          }
        },
        "heroTitle": {
          "type": "string",
          "values": {
            "EN": "imToken x Tether",
            "ZH-Hans": "imToken x Tether",
            "ZH-Hant": "imToken x Tether"
          }
        }
      }
    }
  }]
}
↓
Phase B

在 Figma 中导入 Variable Collection

1

安装 Variable Importer/Exporter 插件

在 Figma 社区搜索 "Variable Importer/Exporter"，安装插件。

2

运行插件 → 选择 Import → 上传 JSON

在 Figma 中打开插件（Plugins → Variable Importer/Exporter），选择 Import 模式，上传 copy-collection.json 文件。

3

确认导入结果

导入后在 Variables Panel 中可以看到 "Copy" Collection，包含 EN / ZH-Hans / ZH-Hant 三个 Mode。

↓
Phase C

使用 Auto-Replace 批量绑定文本图层

1

安装 Auto-Replace Text with Variables 插件

在 Figma 社区搜索安装此插件。

2

选中页面中的所有 Frame → 运行插件

选中包含文本的 Frame（或全选页面），运行 Auto-Replace 插件。插件会自动将文本内容与 Variable 的值进行匹配。

3

检查匹配结果

插件会显示匹配成功和未匹配的文本。对于未匹配的文本（可能是文案有细微差异），手动绑定。

4

切换 Mode 验证

绑定完成后，在 Figma 右侧面板切换 Variable Mode（EN → ZH-Hans → ZH-Hant），验证所有文本正确切换且无排版溢出。

heroTitle Variable bound

匹配原理：Auto-Replace 将文本图层的当前内容与 Variable 的当前 Mode 值进行文本精确匹配。因此需要确保 Figma 中的文案与 i18n 文件中的英文值一致（这也是 Step 01 设计师写 80% 英文文案的原因之一）。

➤ 本步骤产出物

Figma 文件中已创建 "Copy" Variable Collection（104 变量 × 3 语言 Mode），所有文本图层已绑定对应 Variable。可以通过切换 Mode 实时预览不同语言的 UI。
