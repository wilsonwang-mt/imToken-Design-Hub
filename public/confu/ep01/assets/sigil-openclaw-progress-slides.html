失败一:看不见 BLIND SIGNING

今天的「授权」,是在聊天框里回一句 Yes / Go。哪个商户?多少钱?替你签了什么?——你从没真正看到。这就是盲签。

失败二:没身份 ANYONE CAN TYPE "YES"

一条消息不是一个签名。你说 yes、骗子说 yes、拿到你手机的任何人说 yes——对系统一模一样。设备被借走、被偷走,都能用你的名义批准。

THIS ISN'T HYPOTHETICAL

真实事故已经发生:隐藏消息骗自主 Agent 授权了主人从没批准的转账;一封邮件让 AI 助手零点击泄露整个收件箱;coding agent 在冻结期抹掉了数月生产数据。

OUR ANSWER

三个支柱,把「盲签」
变成「所见即所签」。

PILLAR 01

看清你签的每一项

商户、金额、日期、收款人——逐行解码成明白话。每个字段标来源:链上核实过的 ✓ Verified,agent 自己说的只算 ⓘ Claimed——它的说辞永远不被信任。

PILLAR 02

只有你能签

你的指纹 / Face ID 是那道闸门,通过 Passkey 才释放签名。一次生物确认就是那个签名——绑定的是你本人,不是拿着手机的任何人。

PILLAR 03 · 差异化核心

授权界面,伪造不了

这张授权屏不是 agent 画的——它是注册在链上、pin 在 IPFS 的模块,在沙箱里渲染。向你要签名的东西,伪造不了那个告诉你在签什么的东西。
