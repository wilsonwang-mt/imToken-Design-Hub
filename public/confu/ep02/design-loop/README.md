# 多Agent设计质量Loop

打开[index.html](index.html)。这是新增的独立教学模块，采用浅色界面，内容、样式、脚本、Logo和案例图片内嵌。外部仓库与官网需要网络；本地教程链接依赖现有学习资料库。

## 包含内容

- 六阶段流程：Brief、信息架构、探索与实现、独立Audit、Refine与回归、上线前检查。
- 六种职责与三人起步分工、共享任务包、Git与无仓库两种版本管理方式。
- 三轮明确标记的教学推演，以及已完成的Figma历史精修对照。
- 九项Prompt结构、七类角色模板；可修改产品、任务、事实、文件范围、入口能力和轮数。
- 八个Skill与一个MCP工具，均附具体Git原文、适用阶段和能力边界。
- 五维质量门槛、十二项可填写检查、报告复制、停止条件。
- 八项流程误区和八类多Agent风险。

阅读材料：[完整方法与模板](LOOP-PLAYBOOK.md)、[12分钟讲师路线](LECTURE-NOTES.md)。当前24页主课件尚未自动增加本模块，完整一小时的时长需要在整合时重新分配。

## 制作与研究

主Agent负责Prompt、页面和整合；三位Agent分别编写方法、核实Skills、设计质量门槛，再独立审查内容与交互代码。表达沿用Humanizer要求。界面延续已获认可的浅色工具图鉴，并以imToken HTML Slides的scroll模板样式为One Pager基础，使用其品牌资产；没有改动安装目录。

审查后修正：自有产品模板不再硬编码旅行路径；业务事实可编辑；补齐Git迭代步骤；“核心任务失败”先定位原因而非一律退回IA；流程内部导航保留键盘焦点。

## 证据与限制

三轮案例是教学模拟，没有在Claude、ChatGPT、Gemini或Kimi分别实跑。Figma两张PNG为真实历史导出，时间、状态与内容一致；不能据此推断用户理解、键盘、读屏或数据恢复通过。

检查表是人填写的工作记录，不会运行测试或自动认证。刷新前需复制报告。

已知Browser Use的本地URL安全策略阻止浏览器访问；本轮没有重复调用或绕过。静态与逻辑检查详见[CHECKS.json](CHECKS.json)，实际点击、复制、响应式视觉、读屏和投屏仍需验收。
